# Alignment but Flattening

Static GitHub Pages project page for:

**Alignment but Flattening: Analyzing the Trade-off between Cultural Alignment and Diversity in LLMs**

## Files

- `index.html`: page markup
- `styles.css`: responsive styling
- `assets/figure1.png`: Introduction Figure 1
- `assets/tju_badge.png`: Tianjin University badge
- `assets/SUTDLogo_Dark@2x.webp`: SUTD logo
- `.nojekyll`: disables Jekyll processing on GitHub Pages

## Deploy

Upload the contents of this folder to a GitHub Pages repository root, or place them under `docs/` and configure Pages to serve from `docs/`.
